# User Feedback Iteration Summary

The detailed 60-user roster is in [user-feedback-log.md](user-feedback-log.md).

## Feedback profile

- 60 users across `Bill creator` and `Participant` roles for the group bill-splitting escrow
- All feedback written in English (international + domestic tester pool)
- Gmail local parts vary across plain names, numeric suffixes, work suffixes, dots, and dev handles
- Real Stellar testnet public keys generated by `scripts/generate-test-wallets.mjs` and funded via Friendbot

## Improvements

| Feedback theme | Improvement |
| --- | --- |
| Escrow explanation missing on create-bill screen | Add a short escrow explainer above the submit button on the create-bill form. |
| Single-share adjustment not possible | Allow the bill creator to edit one participant's share without rebuilding the bill. |
| Contract method name intimidating | Show a plain-language label for each contract call beside the Freighter popup. |
| Network badge drifts off the wallet chip | Pin the Stellar network + asset badge beside the wallet address on every page. |
| Sharing the bill link is slow | Add a copy-button next to the bill URL so invites are one tap. |
| Success screen hides the recipient | Show the organizer address and the explorer link for the auto-release tx. |
| Wallet on wrong network risk | Detect Horizon network mismatch and surface a clear warning before signing. |
| Address validation gap | Validate Stellar account / contract shape inline when adding participants. |
| Progress hard to scan | Render a per-share progress bar (funded / total) on the bill detail view. |
| USDC trustline surprise | Show a one-line note that USDC needs a trustline before the Enable-USDC button. |
| Refund path unclear after cancel | Surface the on-chain refund path with a participant-by-participant checklist. |
| Reviewer evidence scattered | Keep feedback, wallet, and on-chain tx proofs linked from one package. |
